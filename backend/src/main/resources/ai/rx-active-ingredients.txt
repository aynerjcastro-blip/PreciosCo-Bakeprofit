# HU-39 · RF63 · RN-33 — Principios activos de venta bajo fórmula médica.
#
# Red de seguridad del filtro de droguería: si el NOMBRE de un producto contiene alguno de estos
# términos (palabra completa, sin distinguir tildes ni mayúsculas), el producto no se envía a la IA.
# La otra fuente es la columna products.requires_prescription; basta con que una lo marque.
#
# Reglas para editar:
# - Un término por línea; "#" inicia un comentario.
# - Solo principios que en Colombia se venden con fórmula en TODAS sus presentaciones del catálogo.
#   No agregar los que tienen presentaciones de venta libre (diclofenaco gel, terbinafina crema,
#   clotrimazol, ketoconazol champú, hidrocortisona crema, levonorgestrel de emergencia, ibuprofeno,
#   naproxeno, loratadina, cetirizina...): excluirían productos OTC. Para esos casos se marca la columna.
# - La lista debe revisarla un químico farmacéutico antes de producción.
# - Se pueden agregar términos sin recompilar con preciosco.ai.rx.extra-terms (separados por coma).
